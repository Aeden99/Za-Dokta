# Twisted Periods

Source of <https://aeden99.github.io/Za-Dokta/>, notes on the analytic and algebraic
structure of Feynman integrals. The repository keeps the name Za-Dokta so that the
address of the site does not change.

- `_notes/` holds the notes, one Markdown file each.
- `checks/` holds the scripts that verify the formulas. See [`checks/README.md`](checks/README.md).
- [`SETUP.md`](SETUP.md) has the conventions for adding a note and for building the site locally.

The notes were drafted with Claude (Anthropic). See the About page of the site.
